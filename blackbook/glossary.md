# PROJECT GLOSSARY

---

### A
- **API (Application Programming Interface):** A set of defined protocols and subroutines that enable distinct software systems (e.g. Next.js and Razorpay) to communicate programmatically over HTTP/HTTPS.
- **Agile Methodology:** An iterative software development framework characterized by continuous requirement elicitation, rapid 2-week sprints, adaptive planning, and frequent milestone verification.
- **App Router:** The directory-based routing architecture introduced in Next.js that leverages React Server Components, nested layouts, and serverless route handlers.
- **Artisanal Cafe:** A hospitality establishment specializing in handcrafted, single-origin espresso roasts, slow-fermented bakehouse items, and bespoke culinary preparations.
- **Authentication (Auth):** The security process of verifying the identity of a customer or administrator attempting to access the platform.

### B
- **Barista:** A culinary professional trained in the craft of espresso extraction, milk texturing, beverage customization, and artisanal drink preparation.
- **Beta Testing:** Operational evaluation conducted by a select cohort of end-users in real-world environments to identify defects before full public deployment.
- **Bézier Curve:** A parametric mathematical curve utilized in SVG rendering (`C` command) to produce smooth, continuous historical revenue graphs without jagged step lines.

### C
- **Client Component:** A React component marked with `"use client"` that executes within the customer’s browser, enabling interactive state management, event listeners, and hooks.
- **Cloud Firestore:** A distributed, multi-region NoSQL document-oriented cloud database provided by Google Cloud, featuring atomic operations and real-time WebSocket listeners.
- **CSS (Cascading Style Sheets):** The stylesheet language used to define visual layout, color tokens, typography, and responsive media queries across web documents.

### D
- **Denormalization:** A database design strategy commonly applied in NoSQL systems where related data (e.g. order item snapshots) is embedded directly inside parent records to optimize read throughput.
- **Deployment Diagram:** A UML structural diagram illustrating the physical hardware nodes, network links, and execution environments running software artifacts.
- **Deterministic Math:** A mathematical computation where identical input values consistently yield the exact same output across all execution tiers without round-off discrepancies.

### E
- **Entity-Relationship (ER) Diagram:** A data modeling diagram illustrating the structure of database collections, entities, attributes, primary keys, and cardinality relationships.
- **ETA (Estimated Time of Arrival):** The projected temporal window (standardized to 25 minutes) within which an active cafe order will be prepared and delivered.

### F
- **FCFS (First-Come-First-Served):** An operational queue discipline where orders are processed and prepared strictly in the chronological order of their arrival.
- **Firebase Authentication:** A managed cloud identity service handling user credential validation, JSON Web Tokens (JWT), session lifecycles, and Google OAuth SSO.
- **Framer Motion:** An open-source React animation library utilized for declarative spring physics, slide-over drawer transitions, and layout morphing.

### G
- **Gantt Chart:** A horizontal bar chart illustrating the project schedule, task breakdown, dependencies, and phase-wise temporal milestones across a 12-week timeline.
- **GSAP (GreenSock Animation Platform):** A high-performance JavaScript animation library utilized to render editorial staggered reveal sequences in the landing hero section.
- **GST (Goods and Services Tax):** The statutory 5% value-added tax applied to restaurant food and beverage services in India, calculated via `lib/pricing.js`.

### H
- **HTML5 Canvas:** An immediate-mode bitmapped drawing surface utilized in the user profile drawer to compress high-resolution camera images client-side before network transmission.
- **HTTPS (HyperText Transfer Protocol Secure):** An encrypted communication protocol that utilizes Transport Layer Security (TLS 1.3) to protect financial and personal user data.

### I
- **Immutability:** An architectural property guaranteeing that once an order document is committed to the database, its captured line items and prices cannot be modified or distorted.
- **In-Scope:** The defined boundary of functional requirements, screens, and features that are fully implemented, tested, and verified within the active codebase.

### K
- **Kanban Board:** An agile operational visualization tool utilized in the `/admin` portal displaying active orders across sequential preparation columns.
- **KDS (Kitchen Display System):** A digital hardware display utilized in commercial kitchens to replace physical paper order chits with real-time electronic ticketing.
- **KPI (Key Performance Indicator):** A quantifiable metric (e.g. Total Revenue, Daily Order Count) utilized by store administrators to gauge business operational health.

### L
- **Lenis:** A lightweight JavaScript momentum-based scroll normalization library that ensures smooth, fluid page scrolling across various hardware input devices.
- **Lucide React:** A comprehensive open-source vector icon library providing lightweight, scalable SVG icons across customer and administrative interfaces.

### N
- **Next.js:** An open-source React framework developed by Vercel that provides hybrid static and server rendering, automatic code-splitting, and serverless API route handlers.
- **Nodemailer:** A Node.js module utilized to compile and dispatch transactional HTML email tax invoices over Simple Mail Transfer Protocol (SMTP).
- **NoSQL (Not Only SQL):** A non-relational database paradigm (exemplified by Google Cloud Firestore) utilizing collections and documents instead of tabular relations.

### O
- **OAuth (Open Authorization):** An open standard token-based authentication protocol allowing users to sign in securely utilizing third-party accounts (Google).
- **onSnapshot:** A real-time reactive event listener provided by Google Cloud Firestore that immediately pushes database document mutations to connected client viewports.

### P
- **PCI-DSS (Payment Card Industry Data Security Standard):** An information security standard mandated for organizations handling branded credit and debit cards, strictly complied with via Razorpay.
- **Point-in-Time Snapshot:** An architectural pattern that captures a frozen copy of item titles and prices at the moment of checkout, ensuring historical accounting accuracy.

### R
- **Razorpay:** An Indian payment gateway provider enabling online payment collection via UPI, Credit/Debit cards, and Netbanking through a client modal interface.
- **React:** A declarative, component-based front-end JavaScript library developed by Meta Platforms for building high-performance, dynamic user interfaces.
- **Responsive Web Design:** An engineering approach ensuring that web interfaces automatically adapt visual layouts across smartphones, tablets, and desktop displays.

### S
- **Serverless Computing:** A cloud-native execution model where cloud providers dynamically manage server allocation, executing backend route handlers on-demand without dedicated physical servers.
- **SMTP (Simple Mail Transfer Protocol):** An Internet communication protocol used for transmitting electronic mail messages across network nodes, utilized by Nodemailer.
- **SVG (Scalable Vector Graphics):** An XML-based vector image format utilized to render the 12-month interactive revenue analytics curve in the administrative dashboard.

### T
- **Tailwind CSS:** A utility-first CSS framework providing atomic styling classes, responsive breakpoint prefixes, and customizable theme design tokens.
- **Test Case:** A formal specification of inputs, execution preconditions, testing steps, and expected results designed to verify a specific software requirement.

### U
- **UML (Unified Modeling Language):** A standardized visual modeling language used in software engineering to specify, visualize, and document system architecture and workflows.
- **UAT (User Acceptance Testing):** The final phase of software verification wherein representative users evaluate the platform to confirm compliance with real-world requirements.
- **URI / URL (Uniform Resource Identifier / Locator):** A standardized string of characters that references a specific network resource or web route within the application.
